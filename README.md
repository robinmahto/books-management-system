# Books Management System

## About
Personal Book Manager is a simple web application that helps users organize and track their personal book collection. Users can securely sign up, log in, and manage their own library by adding, editing, or deleting books. Books can be categorized as **Want to Read**, **Reading**, or **Completed**, with support for filtering by tags and reading status. A clean dashboard provides an overview of the collection and reading progress. Built with **Next.js, Node.js, Express.js, MongoDB, and JWT Authentication**, the application focuses on simplicity, performance, and a smooth user experience.

## Core Features

- Secure user authentication (Sign Up, Login & Logout)
- JWT-based authentication with protected routes
- Add, edit, and delete books
- Track reading status (Want to Read, Reading, Completed)
- Organize books using custom tags
- Filter books by tags and reading status
- Dashboard with reading statistics and book overview
- Fully responsive design for desktop, tablet, and mobile
- Fast and intuitive user experience
- Clean and modern user interface


## Tech Stack

- **Frontend:** Next.js(App Router) 
- **Styling:** Tailwind CSS v4
- **Backend:**  Next.js API routes
- **Database:** MongoDB
- **Auth:** JWT
